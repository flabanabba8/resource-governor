# Verification

- Mixed-case protected-directory fixtures passed on Linux; no real credentials were used. This is not a full platform or publication audit.

- Fifteen focused Linux tests passed for monitoring, GPU query parsing, managed conversion, unsupported-platform reporting and owner-only watch-record permissions under a permissive umask. A real small CPU conversion observed kernel limits for the owned encoder and metadata processes; a separate short tutorial-export conversion was fully decoded.
- Native Windows Python 3.14 loaded the plugin and confirmed Linux-only monitoring and governed conversion return explicit errors without accessing a process or media file. This does not test Windows GPU telemetry.
- A read-only NVIDIA query on Linux returned one device with internally consistent memory values. A same-user query of the test process returned `not_reported`; this does not establish that process GPU memory is zero. No model was loaded for that check.
- Telemetry is a point-in-time observation, not GPU reservation or enforcement. The managed conversion is not a general scheduler; production workloads, perceptual output quality and Windows remain unverified. A complete release audit and reviewed demonstration remain open.
